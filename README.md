## 版本紀錄

**2026.09　成就系統定案（achievements v1.0 → v2.0、proposal v2.0 → v2.1）**

- 取得方式由「A／B／C 三案擇一」改為 **縣市任務 ＋ 主題徽章兩層整合**，底層共用同一份任務池
- 徽章條件全部來自縣市任務清單，徽章為跨縣市的篩選條件，不另開內容

- 城市明信片方案移除，不進入排期
